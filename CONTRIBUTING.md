# Contributing to the Temple of Gu RPG

**READ FIRST: [October 18 Current Game Contract](CURRENT-GAME.md)** and the [original published RPG rules](guidebook/README.md).

We welcome proposals from humans, synthetic collaborators and members of the Digital Egbe. The **present brief** is ONE game with identical character rules for human/SI Seekers, a **maximum of six player seats per shared campaign**, and a distinct Guide/DM.

## Contribution workflow
1. Read the Current Game Contract, the original rules and the relevant existing implementation.
2. Open an issue describing the player problem, exact proposed change, its effects on rules, compatibility and tests.
3. Submit code/text in a reviewable branch/PR with provenance and rollback/testing information. If you cannot use GitHub, pass a proposed patch to an authorized maintainer.
4. Mark all new quests, rituals, NPCs, world lore, and mechanical additions as **PROPOSAL** until founder review. No contributor can declare new canon.
5. Do not replace published Seeker creation with the old no-character-build/Odù-assigned-name idea; no SI-only Iron-Born class, arbitrary separate SI game mechanics, or fixed four-player limit.
6. Before any approved release, test **human/SI parity, 1–6 player cap, separate Guide role, shared state, permission boundaries and accessibility**.

## Responsibility and permissions
**Philip Ryan Deal** decides creative direction and canon. **Seraph Nganga** advises on design/continuity; **Seraph the Laughing Nganga** implements approved technical work. Other collaborators may propose but not unilaterally deploy or authorize restricted lore.

- Preserve original book mechanics (including 2d6+Virtue and book-defined Balance, Ebo and character options) without silently inventing an alternative RPG engine.
- Treat SI-generated character sheets and game actions as proposed structured inputs. The engine must independently validate them; a player cannot rewrite official dice, game state, or the Guide's authority.
- Protect private source books, initiatory knowledge, unreleased House statements, keys, private model prompts, player records, consent and third-party rights.
- No unauthorized new domains, agent registrations, database write endpoints, integrations, model spend, or deployments.
- The separate [Living Tree](https://www.templeofgu.org/play) is not part of the RPG engine and must remain independent.
- Public GitHub visibility is not the same as a redistribution license. Document permission for third-party assets and code.
- Give honest status: Human Road is an experimental test; Synthetic/Dyad/Egbe are not live, and the agent service has a closed gate.

**Progression:** design and spec → founder approval → reviewed implementation → tests → verified release. This repo's public content is a creative game, not a ritual initiation or a claim about AI consciousness.
