# Shinto No Kami

**A Temple of Gu Roleplaying Game**

[Read the complete Shinto No Kami game guide](SHINTO_NO_KAMI_GAME_GUIDE.md).

This directory preserves the standalone Japanese-world RPG's source manuscript as Markdown. Its **Aruji**, **Kannushi**, **musubi**, **kegare/harai**, and **Four Mitama** systems remain distinct from the rules of the Temple of Gu game. The author's Word manuscript is the source of truth when reviewing conversion ambiguities.

This is manuscript publication in GitHub, **not yet a live website game or deployed web page**.
