# Call of the Taíno

**Temple of Gu: Call of the Taíno** — a tabletop RPG expansion by Philip Ryan Deal.

[Read the full Markdown guidebook](CALL_OF_THE_TAINO_GAME_GUIDE.md).

This manuscript describes a distinct Taíno-centered setting and expansion of the core Temple of Gu RPG, including the three realms, four sacred callings, twelve Attunements, the Zemí, rituals, regional mysteries, and Guide resources. It explicitly builds on the core game's Seeker, Guide, 2d6, Virtue, Mystery, Breakthrough, and Ebo vocabulary.

The author's supplied Word document is the authoritative reference if the Markdown conversion presents ambiguity. This directory holds the manuscript; it does not deploy or modify the live Temple website.
